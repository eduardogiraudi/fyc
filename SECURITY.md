# Security policy for fuckyourcli

| | |
|---|---|
| **Last reviewed** | 2026-09-22 |
| **Applies to** | fuckyourcli repository and all its releases |

---

## Reporting a vulnerability

- **GitHub private vulnerability reporting.** Please use the private reporting form at: `https://github.com/eduardogiraudi/fyc/security/advisories/new`
- **Email fallback.** If you encounter issues with GitHub, you can reach out to `eduardogiraudi000@gmail.com`.

> Do **not** open public GitHub issues or pull requests for unpatched vulnerabilities.

## Report contents

To make your report actionable, please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue (or a proof of concept).
- The version of `fuckyourcli` being used.
- The environment (OS) where the issue was found.

## Response

1. Your report will be acknowledged within 7 days.
2. You will receive a more detailed response within 14 days indicating the next steps.
3. A CVE will be requested via GitHub for confirmed vulnerabilities.
4. The reporter will be credited in the security advisory.

## Supported versions

Only the latest stable release of `fuckyourcli` is supported for security fixes.

## Out of scope

Defects in third-party modules or infrastructure that the user has explicitly configured or installed as part of their environment are not considered within the scope of this policy. Please report such issues directly to the respective maintainers.
